Adds a clean one-click Clone action to your posts and pages to duplicate content, categories, and featured images into a new draft.

== Description ==

Re-creating similar posts or landing pages from scratch is a huge waste of time. Most WordPress users waste hours copy-pasting headings, resetting featured images, and re-checking category boxes.

Ocasio Duplicate Post Button adds a simple **Clone** action right inside your WordPress post and page lists. Hover over any post, click Clone, and you get an exact duplicate saved as a new draft in one second.

You don't have to deal with bloated settings or complicated menus. It just works right where you need it.

= What Gets Cloned =

* **Post Title & Content:** Duplicates your complete written content and formatting into `[Title] (Copy)`.
* **Featured Image:** Preserves your featured image thumbnail on the new draft.
* **Categories & Tags:** Keeps all assigned terms, tags, and custom taxonomies intact.
* **Custom Meta Fields:** Copies your custom field values and page template settings.
* **Draft Status:** Always creates the duplicate as a safe draft so you never publish incomplete work by accident.

= Features =

* **1-Click Cloning:** Clone any post or page directly from your WordPress admin list tables.
* **Custom Post Type Support:** Choose exactly which content types show the Clone action in settings.
* **Zero Front-End Assets:** Loads 0 bytes of CSS or JavaScript on your public website.
* **Instant Editor Redirect:** Takes you straight to the edit screen of your new draft so you can start working immediately.

== Installation ==

1. Upload the `ocasio-duplicate-post-button` folder to your `/wp-content/plugins/` directory, or install it directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Hover over any post or page in your admin list and click **Clone**.
4. To choose specific post types, go to **Ocasio Plugins -> Duplicate Post**.

== Frequently Asked Questions ==

= Does cloning a post publish it immediately? =
No. Cloned posts are always saved as a **Draft** so you can edit and review them before publishing.

= Can I use this on custom post types? =
Yes. Go to **Ocasio Plugins -> Duplicate Post** and check the box next to any custom post type registered on your site.

= Does this plugin slow down my website? =
No. The plugin only runs inside your WordPress admin dashboard and loads zero files on your live public pages.
